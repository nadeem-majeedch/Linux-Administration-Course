# Module 01 — Practice

Self-assessment material. Try honestly *before* opening the answer key — retrieval
is where the learning happens.

| File | What it is | When |
|---|---|---|
| [quiz.md](quiz.md) | 30 questions across all 8 lessons (mix of recall, understanding, prediction) | After all lessons & labs |
| [quiz-answers.md](quiz-answers.md) | Answer key with explanations | After attempting |
| [challenges.md](challenges.md) | 10 open-ended challenges (research, argument, mini-builds) | Anytime after Lab 1; ≥3 required |

Passing bar for the module: **24/30** on the quiz and **3 challenges** attempted
(attempt = honest write-up in `lab-log.md`, not necessarily success — the log
records the try).
