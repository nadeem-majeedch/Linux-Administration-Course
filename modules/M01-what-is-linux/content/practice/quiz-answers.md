# Module 01 Quiz — Answer Key

Score yourself honestly; explanations matter more than the number.

1. **Software layer between hardware and applications** that runs programs, manages
   memory, files, and hardware.
2. **The kernel** — the core program managing CPU, memory, devices. (Broad everyday
   use: kernel + userland.)
3. The **userland**: shell and core utilities. From the lessons: **bash**, **ls**,
   **cp/grep/awk** (any three GNU tools; glibc also acceptable).
4. **Linus Torvalds**, Finland (University of Helsinki), **1991**.
5. Android's foundation **is the Linux kernel**; vendors put their own brand/UI on
   top. "Linux" the kernel is invisible to the user.
6. **Copyleft** (GPLv2/v3, AGPL) — share source of derivatives; **permissive**
   (MIT, BSD, Apache-2.0) — minimal conditions.
7. macOS descends from **BSD Unix** and passes the certification; Linux is a
   *re-implementation* without Unix lineage code. Doesn't matter because both are
   **POSIX-conformant in practice** — the commands and concepts transfer.
8. Any four: **userland (GNU tools/shell), installer, package manager +
   repositories, desktop environment, release policy, defaults/branding**.
9. .deb/`apt` → **Debian family**; .rpm/`dnf` → **Red Hat family**.
10. LTS = **Long Term Support**: Ubuntu LTS every **2 years**, **5 years** of
    security updates. Servers prefer it for the long, stable support window — no
    forced rebuilds every 9 months.
11. No — `dnf` is Red Hat-family. On Debian-family: **`apt install tree`** (or
    `sudo apt install tree`).
12. Rolling reasonable: a **personal enthusiast desktop** where you want latest
    software and accept occasional breakage. Bad: an **unattended production
    server** (e.g., nightly training host) where surprise updates are risk, not
    value.
13. Runs programs (scheduling), manages **memory**, manages **files**, talks to
    **hardware**.
14. The boundary is privilege level; the mechanism is the **system call (syscall)
    interface**.
15. The loop runs in **user space**; the **kernel** scheduler keeps time-slicing
    between all processes, and the user/kernel wall prevents the runaway process
    from taking the machine down — worst case it gets killed.
16. **Generated by the kernel on read** — it's a virtual file in `/proc`, not disk
    storage. You know because `/proc` is a kernel-provided virtual filesystem
    (and its size reads as 0).
17. A **background service program**, usually started at boot, no terminal:
    e.g., **systemd, journald, sshd, cron** (any two).
18. **Available** (3.0 GiB). It includes reclaimable caches; *free* alone
    underestimates usable memory. A 2.5 GB load fits within 3.0 GiB available.
19. **Console** = the machine's own text log-in (historically the physical
    keyboard/monitor); **terminal** = the emulator window hosting a text session;
    **shell** = the program interpreting commands inside it.
20. `$` = **normal user**; the opposite is **`#`** = root (admin) shell.
21. **Three** arguments (`one`, `two`, `three`); echo prints `one two three`.
22. **One** argument containing the spaces; prints with the spacing preserved.
23. **Ctrl+C** interrupt; **Ctrl+L** (or `clear`) clear screen; **↑** previous
    command; **Ctrl+R** history search.
24. 1 = **user commands** (e.g., `ls`); 5 = **file formats** (e.g., `/etc/fstab`);
    8 = **admin commands** (e.g., `mount`).
25. **`man 5 crontab`**.
26. **`help <name>`** (bash's builtin help); find out with **`type <name>`** —
    it answers "shell builtin" vs "…is /usr/bin/…".
27. **Two required** (SOURCE, DEST); **options** may repeat (`...`).
28. `ls -l -h`, `ls -lh`, `ls -l -h` variants — idiomatic: **`ls -lh`** (combined
    short options).
29. Non-zero — typically **1** (GNU coreutils usage error) or 2; the point: **≠0
    means failure**, 0 means success.
30. **End of options marker**: everything after `--` is an argument, even if it
    looks like an option. Prevents arguments *named like options* (a file called
    `-r`) from being parsed as flags.

**Scoring:** 24+/30 → ready for Module 02. 18–23 → revisit the flagged sections;
the answer key names each lesson. <18 → re-run the labs; fluency, not memory, is
the gap.
