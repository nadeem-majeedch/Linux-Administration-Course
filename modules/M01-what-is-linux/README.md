# M01 — What Is Linux?

> Unit 1 · Foundations of Linux
> Difficulty: Beginner · Prerequisites: none

**Status: content complete.** The full lesson set for this module lives in
[content/](content/README.md): 8 lessons covering all foundation topics (what Linux
is, Unix lineage, distributions, Ubuntu, kernel, GNU/Linux, architecture, user vs
kernel space, shell, terminal, CLI vs GUI, open source, servers/cloud/DS use,
installing Linux, VMs, WSL2, Ubuntu setup, first login, terminal orientation,
getting help, man/info/help, command syntax, options and arguments) plus 4 labs,
quiz, challenges, and a troubleshooting guide.

This file remains the module's contract: scope, placement, and completion criteria.

## What this module covers

Kernel vs distribution vs desktop environment; why Linux dominates servers, cloud, and ML infrastructure; first read-only contact with the terminal.

The full specification — learning objectives, concepts, command-line skills,
laboratory, exercises, mini-project, and the Data Science connection — lives in
[COURSE-ROADMAP.md](../../COURSE-ROADMAP.md), Unit 1.
