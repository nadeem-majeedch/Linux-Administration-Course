# Assignments

> Take-home specifications between exams. Three assignments, one per
> third of the course, each bridging its modules into the next
> unit's material. All follow the course philosophy: the deliverable
> is a *working artifact plus evidence*, never a description of one.

## Common rules

- **Evidence bundle:** every submission includes a `script`-session
  transcript (or command log) alongside the artifacts. An artifact
  without its evidence line is treated as not existing.
- **Environment:** your own VM (WSL2/Docker tracks accepted where
  stated in the spec).
- **Integrity:** discuss freely, type alone. Identical transcripts
  are treated like identical essays.
- **Late policy & rubrics** are stated in each spec; all grading is
  against the course evidence standard (result-only caps at 60%).
