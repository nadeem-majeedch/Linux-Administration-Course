# projects/

Larger deliverables that span multiple modules. Every project has a brief, a rubric,
and a place to submit (per instructor).

- **Mini-projects** live in [`mini-projects/`](mini-projects/) — standalone briefs
  A–F tied to the roadmap (A: M10, B: M13, C: M18, D: M22, E: M24, F: M27).
- **The capstone** lives in [`capstone/`](capstone/) — the M30 deliverable with its
  phased brief, grading rubric, and starter files.

Project work is graded on operational evidence (logs, runbooks, tested restores,
clean Git history) — not on polish alone. See each brief for its rubric.
