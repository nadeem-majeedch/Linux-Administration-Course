# Capstone — M30

The course's final deliverable: a complete, deployed, documented, monitored
data-science system on your own Ubuntu VM.

| Document | Purpose |
|---|---|
| [BRIEF.md](BRIEF.md) | The assignment: phases, required components, deliverables |
| [RUBRIC.md](RUBRIC.md) | How it is graded (100 points) |
| [STARTER.md](STARTER.md) | Suggested repository layout and starting checklist |

**Timeline (suggested 5 weeks):** proposal → build → operate → document → present.
Detailed phase descriptions are in [BRIEF.md](BRIEF.md).

**The one rule:** operational evidence beats polish. Logs, tested restores,
runbooks, and clean history are the graded artifacts — a simple, reliable,
monitored pipeline outscores a fancy broken one.
