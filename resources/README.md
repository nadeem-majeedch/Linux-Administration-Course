# resources/

Student-facing reference material, kept separate from the linear module flow.

- [`cheatsheets/`](cheatsheets/) — one printable page per unit (plus a safety card).
- [`glossary.md`](glossary.md) — plain-language definitions of every term the course uses.
- [`references.md`](references.md) — curated links to **official documentation only**:
  Ubuntu docs, kernel.org, GNU manuals, systemd docs, and tool homepages.

References policy: links must resolve and point to primary sources (official docs or
man pages). If a better official source appears, update the link in a PR.
