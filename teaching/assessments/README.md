# Assessment Framework — Teaching Package

> How the course's assessments fit a 16-week delivery. The repository's
> own assessment bank ([../../assessments/README.md](../../assessments/README.md))
> remains canonical — this layer adds *formats and keys* it lacked, and
> routes everything else by pointer. Nothing here replaces an existing
> instrument.

## Weightings (repository-authoritative, unchanged)

quizzes 10% · lab assessments 10% · assignments 3×5% (A1–A3) ·
midterm 20% · final 25% · practical 15% · capstone per its rubric.
**A4–A6 are optional replacements/enrichment** — adopt one only by
substituting it for an existing assignment weight, not by adding load.
The calendar is in the [teaching plan](../teaching-plan/assessment-schedule.md).

## Design rules this framework inherits

1. Evidence over claims — transcripts, quoted output, method visibility
2. No cheatsheet-answerable items — scenarios always carry the evidence
3. Keys separated from student papers — always, in every format
4. CLOs cited as **proposed** ([alignment matrix](../../accreditation/CLO-ASSESSMENT-ALIGNMENT.md))
5. Safe-by-default — no instrument requires damaging a system; breakage
   is staged and reversible
