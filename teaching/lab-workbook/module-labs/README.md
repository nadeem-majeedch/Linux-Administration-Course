Each index contains:

- **The lab table** — module, duration, difficulty (★–★★★), deliverable,
  and the direct link into the module's lab
- **Session mapping** — which lab runs in which session
- **Checkpoints that matter most** — where the graded thinking lives
- **Extension routing** — the ★★★ challenges for early finishers
- **Instructor staging** — what must be pre-staged, with a link to the
  [infrastructure checklist](../../setup-and-delivery/lab-infrastructure.md)
- **After this unit** — which graded instrument (LA circuit, assignment,
  exam) this unit rehearses

Graded circuits (LA-1…LA-5) are *not* duplicated here — they live in
[assessments/lab-assessments/](../../../assessments/lab-assessments/README.md)
with their rubrics; each unit index names when its circuit lands.
