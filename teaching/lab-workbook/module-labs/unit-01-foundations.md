## Session mapping

- **S1**: no lab (SETUP walkthrough starts; finish at home)
- **S2**: 8-check verification (setup guide) → **one** in-class lab:
  first-login tour (M01 lab 1, 20′). The M02 identification circuit
  (30′ as written) is the HW follow-up — full circuit at home, Part A
  warm-up if time allows
- **S3**: install lab — the session *is* the lab
- **S4**: snapshot drills (M04 lab 1 Part D) + anatomy tour; WSL2
  track (M04 lab 2) as homework for Path-B students

## What the graded future looks like

LA-1 (week 4 of Unit 2) tests navigation/files — nothing here is graded
beyond completion *by design*: weeks 1–2 build the machine and the
transcript habit without grade pressure.

## Extension routing (★★★)

- M04: LVM install with a volume-group explanation (reading level)
- M03: `strace ls` one-line demonstration report

## Instructor staging

None required — this unit's labs run on fresh student VMs. Verify the
[infrastructure checklist](../../setup-and-delivery/lab-infrastructure.md)
items 1–3 (ISOs, projector legibility, spare seats) before S3.
