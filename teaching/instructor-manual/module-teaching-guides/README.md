## Every guide answers, per module

1. **Teaching objectives** — what the session must accomplish (beyond
   the module's student-facing objectives)
2. **Suggested sequence** — the order that respects prerequisite
   loading
3. **Difficult concepts** — where the wall is, and the scaffold
4. **Common student mistakes** — from the [misconception bank](../common-misconceptions.md),
   unit-localized
5. **Demonstration plan** — which demos, in what order, with fallbacks
6. **Practical activity** — which lab, which checkpoints matter, the
   cut slice
7. **Questions for discussion** — the ones that produce thinking, not
   recall
8. **Assessment suggestions** — formative checks + which graded
   instrument this feeds
9. **Extension activity** — the ★★★ challenge routing for the fast
   finishers
10. **Troubleshooting guide** — what breaks in *class* (not in the
    students' labs — the modules cover that)
