## The manual in one paragraph

Teach with **Predict → Run → Explain**; treat **mistakes as the method**
(snapshots make them safe); grade **evidence, not claims**; name
misconceptions as they surface using the bank; keep every dangerous
command wrapped in **purpose–risk–environment–recovery**; and route
struggling students to VM-triage 1:1s by week 4, because the course's
evidence format tells you who needs it before they do.
