## How to revise this course (the honest method)

Exams here grade **reasoning from evidence**, so re-reading notes
trains the wrong skill. The loop that works:

1. **Re-do, don't re-read.** Pick a lab you finished weeks ago and
   repeat it cold. Where you fumble is your real gap list.
2. **Explain aloud.** Every command you type in practice, say *why*
   out loud. The viva samples exactly this.
3. **Drill the six-rung ladder.** Connectivity, resolution, route,
   port, service, app — until the order is reflex ([M21 lesson 5]).
4. **Time-box one past-style paper.** Midterm/final papers are in
   `assessments/exams/` — sit one closed-book before touching the key.
5. **Sleep before.** The method-under-pressure skill is what's being
   sampled; it degrades fastest.
